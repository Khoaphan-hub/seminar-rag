[Phan Anh Khoa · 70 seconds] Lewis and colleagues frame RAG as combining two kinds of memory. Parametric memory is knowledge stored in the learned weights of a model. Non-parametric memory is an external store that is searched at question time. Non-parametric describes where the knowledge is kept; the encoders that search it can still have learned parameters. The table compares three options. Fine-tuning changes the weights, so updating usually means training again. A full-document prompt simply supplies everything as input, which is easy but limited by context size. RAG retrieves only the top passages and then generates, so updating means changing the store and its index. These approaches can also be combined. In the original paper, the query encoder and the BART generator are trained while the document index stays fixed. Our demo does not retrain anything; it uses pretrained components.
